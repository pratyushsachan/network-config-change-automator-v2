# NetShift Frontend

Modern, animated React frontend for the Network Config Change Automator.

## Features

- **Devices Tab**: Browse network devices by group
- **Changes Tab**: Create, approve, and manage configuration changes
- **Dry Run**: Preview exactly what would change
- **Audit Log**: Complete history of all actions
- **Animations**: Smooth transitions and interactive elements
- **Responsive Design**: Works on desktop and mobile
- **Mock Data**: Works standalone without backend

## Tech Stack

- React 18
- Tailwind CSS
- Framer Motion (animations)
- Lucide Icons

## Development

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Deployment to Vercel

1. Push this folder to GitHub
2. Go to [vercel.com](https://vercel.com)
3. Click "New Project"
4. Import the GitHub repo
5. Set root directory to `frontend/`
6. Deploy

## Build

```bash
npm run build
```

Builds the app for production in the `build` folder.
